# 把 pdf-studio 接到手机远控（模式文档）

> **实现不在本仓库** ✓ —— 可运行的桥接器、手机网页与 Android App 都在 **`pdf-studio-mobile`（cnb.cool）** 仓库 ✓。
> 这里只记录**模式、边界与踩过的坑** ✓ 供你自己搭一套或照着改 ✓。

## 它解决什么

让**手机（任何网络）**把 PDF 任务交给**家里的电脑**跑 `dsh --profile headless` + 本插件的 `pdf_*` 工具，
产物再回手机（可一键转发到微信）✓ —— 全程**不需要公网 IP、不需要端口映射**（电脑主动出网 ✓）。

```
手机 ─┬─ 飞书群：发文件 + /预设名         （零安装 ✓ 从任何网络可用 ✓）
      └─ 手机网页 / App（HTTPS）→ 选 PDF → 点按钮 → 下载 / 一键转发微信 ✓
                     │
       电脑（常驻）：白名单 → 去重 → 单飞队列 → dsh headless → outbox → 回传
```

## 两条通道（按"用户要装什么"选）

| 通道 | 用户要装 | 从任何网络 | 备注 |
|---|---|---|---|
| **飞书** | 什么都不用装 ✓ | ✅ | 群机器人**只收 @它的消息**，而**文件消息带不了 @** ✗ → 收文件必须走**轮询 + user 身份读** ✓ |
| **网页（PWA）** | 零安装 ✓（可"添加到主屏幕" ✓） | ✅ | 界面就是一张单文件网页 ✓ **改网页 = 改 App** ✓ |
| **Android App** | 1 个 APK ✓ | ✅ | WebView 装同一个网页 ✓ + **分享目标**（微信里长按文件即可派活 ✓）+ 通知 ✓ |

## 关键：HTTPS 是"一键转发微信"的前提

浏览器的 **Web Share API 只在安全上下文（HTTPS）**下才提供 ✗ —— http 页面上 `navigator.canShare` 根本不存在 ✓。
所以想"点一下就调起微信分享（文件一起带过去）"，必须给页面一个**真证书的 https 地址** ✓。

国内可达性的实测结论（供选型 ✓）：

| 方案 | 国内能不能直连 | 说明 |
|---|---|---|
| **Tailscale Funnel** | ⚠️ 视网络而定 | `*.ts.net` 在部分网络/公共 DNS 上解析不到 ✗，但**手机流量实测可直连** ✓；**只需装在电脑上** ✓ 手机不用装 ✓ → **推荐** ✓ |
| Cloudflare 隧道 | ❌ 多数被墙 | 实测 **7844 端口被封** ✗（QUIC 与 TCP 都失败 ✓） |
| 境外小 VPS | ✅ 最稳 | 把整套跑在境外（**不需要 ICP 备案** ✓）✓ 代价是月费 + 模型费用 ✓ |

## 安全边界（照抄这几条，别省 ✓）

- **fail-closed**：白名单/必要配置缺失 → 配置非法，拒绝启动 ✓
- 只认**白名单发送者**与**目标会话** ✓；**`message_id` 去重**且持久化 ✓
- **单飞队列**（一次只跑一个任务 ✓）+ **背压**（队列满 → 明确拒收 ✓）
- **绝不执行 shell**：`spawn` 不传 shell ✓ 消息文本只作为 argv 元素 ✓
- 提示词硬约束：只能 `pdf_*` 工具 ✓ 只能写 outbox ✓ 源文件永不覆盖 ✓
- 回传只取 outbox 产物 + 扩展名/大小白名单 ✓ 排除 `~$` / `._` / `.part` ✓
- 挂在公网必须加：**请求限流 + 每人每日配额 + 多 token（每人一个 ✓）** ✓ 口令 <16 位拒绝启动 ✓
- 长任务**杀整个进程组**（SIGTERM → 宽限 → SIGKILL ✓），别留孤儿 ✓

## 踩过的坑（最值钱的一节 ✓）

| 坑 | 真相 |
|---|---|
| 群里发文件机器人没反应 | **文件消息带不了 @** ✗ 而群机器人只收被 @ 的消息 ✗ → 必须轮询 + `read_user` 身份读 ✓ |
| 回执一直没收到产物 | `lark-cli` 的 `--file` **只接受 cwd 下的相对路径** ✗ → 用 `cwd=目录 + basename` ✓ |
| 任务标题以 "headless" 开头 | `dsh` 会把**多个位置参数用空格拼起来** ✗ → 任务正文必须是**最后一个**位置参数 ✓ |
| 网页选了文件却"没选" | 安卓上 `FileList` **不是真数组** ✗（没有 `forEach` ✓）；且**不要在选完后清空 input** ✗（会连 FileList 一起清 ✓） |
| 网页"查不到产物" | 传给队列的 `taskId` **没转发给执行器** ✗ → 任务跑在另一个目录名下 ✓（飞书收到了、网页查不到 ✓）→ 修法：**记录实际交付的产物**而不是事后扫目录 ✓ |
| 标签写着试卷、下载的是答案 | 下载按"重新列一遍的序号"取 ✗ → 两处白名单/目录一变就错位 ✓ → **按文件名取** ✓ |
| 装完 Tailscale 后 Clash 不能上网 | Tailscale **默认接管 DNS**（MagicDNS）✗ → `tailscale set --accept-dns=false` ✓ |
| 删水印把邻行也删了 | 判定用了"距离容差" ✗ 而水印常是"小字号 + 大 CTM 缩放" ✓ → 改成**行带判定**（基线落在行内）+ **写盘前复核**（目标外少一行就拒绝输出 ✓） |

## 上线常驻（macOS）

- 桥接器：`launchd` LaunchAgent ✓（`KeepAlive` 崩溃自愈 ✓ 重启后自动恢复 ✓）
- **防睡眠**：`caffeinate -dimsu` 的 LaunchAgent ✓；并确认 `pmset` 里接电源时 `sleep 0` ✓；**别合盖** ✗（没外接显示器时合盖仍会睡 ✓）
- HTTPS：`tailscale funnel --bg <端口>` ✓（Funnel 需要先在管理后台开启 ✓）
